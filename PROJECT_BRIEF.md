# Project Brief: SupportSense

**Business:** Northstar Cloud is a fictional B2B SaaS company with recurring support questions about billing, account security, API limits, exports, and troubleshooting.

**Problem:** Agents spend time locating policy details and risk inconsistent responses.

**Solution:** A document-grounded assistant that retrieves approved passages, returns source IDs, and abstains when evidence is insufficient.

**Experiment:** A paired offline benchmark compares top-passage search with grounded answer synthesis. A live randomized A/B test is a future phase, not part of this repository.

**Non-goals:** No real customer data, no real company affiliation, and no claim that synthetic benchmark results prove business lift.
